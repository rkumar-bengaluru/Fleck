# Fleck MVP mockups

Design mockups for review before the build. Live canvas (private to rupak.k): https://claude.ai/artifact/RXtZWetfZF7J2VZncQJWtM

The `.dc.html` files are the canvas sources; they need the canvas runtime and don't open as plain web pages. `canvas.json` is the layout.

| File | Screen |
|---|---|
| `Main.dc.html` | Desktop: answer panel over the call |
| `PanelStates.dc.html` | Desktop: panel states (thinking, general knowledge, not in our material, reference contract) |
| `MenuBar.dc.html` | Desktop: 5-minute notification and menu-bar menu |
| `WebToday.dc.html` | Web: Today, with client link per meeting |
| `WebBrief.dc.html` | Web: pre-meeting brief |
| `WebLive.dc.html` | Web: meeting, live |
| `WebAfter.dc.html` | Web: after the meeting (timeline, where Fleck helped, used markers, notes, chat) |
| `WebLibrary.dc.html` | Web: library |

Names (Harbourline Legal, Calloway & Marsh, Orion Freight, Kestrel Insurance) are fictional. Rates and FAQ answers come from `clients/_firm/`.
