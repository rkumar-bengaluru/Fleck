# Fleck MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A desktop presales assistant that hears the client's questions during a call and shows a cited answer from the firm's library in a floating panel within 3 s, then gives the team notes, "used it" markers and chat after the meeting.

**Architecture:** A native Python menu-bar helper on the Mac runs the whole live path (capture or WAV replay → VAD → speaker gate → mlx-whisper → rule classifier → Weaviate search → `qwen3:8b` via Ollama → citation and number checks → floating panel). It streams segments, assists and audio to a FastAPI api in Docker, which stores them (Postgres, MinIO) and relays them to a React web app. A worker (same codebase as the api, Postgres job queue) does library indexing, calendar sync, recording assembly, summaries, "used it" markers and briefs. Shared pure-Python logic (number normalisation, validators, event schema, retrieval) lives in one `core` package used by helper, api and worker.

**Tech Stack:** Python 3.12 + uv workspace (FastAPI, SQLAlchemy 2, Alembic, psycopg 3, weaviate-client v4, anthropic, markitdown, openpyxl, text2num, webrtcvad-wheels, mlx-whisper, rumps, PyObjC, py2app); React 18 + Vite + TypeScript + pnpm, Vitest, Playwright; Docker Compose (postgres 16, minio, weaviate 1.3x); Ollama native.

**Spec:** `docs/superpowers/specs/2026-10-30-fleck-mvp-design.md` (merged PR #2). Mockups: `docs/superpowers/mockups/` and https://claude.ai/artifact/RXtZWetfZF7J2VZncQJWtM. Executors read the spec section each task names.

## Review Focus

1. **Bleed: the client's words appear in the You stream** (speakers, imperfect echo cancellation). Expect: they never trigger (gate = overlap or you) and a You final matching a Client final within ±2 s is dropped from the transcript. Test in Task 11 (`test_bleed_you_duplicates_dropped`) and Task 12 (`conversation_false_triggers` on the bleed WAV).
2. **Ollama or Weaviate down or slow mid-meeting.** Expect: the panel shows **Not in our material** for that question within 8 s, recording and transcript continue, the error is in the trace. Tests in Task 13 (`test_answer_timeout_degrades`) and Task 14 (`test_retrieval_error_degrades`).
3. **Empty or tiny library, or no client linked.** Expect: live questions fall back (or **Not in our material** with fallback off), the brief is built from the event title only, nothing crashes. Tests in Task 14 (`test_empty_library_falls_back`) and Task 20 (`test_brief_without_client`).
4. **Unsupported or broken upload** (`.key`, encrypted PDF, 0-byte file). Expect: document marked `failed` with a readable reason, other documents still index. Test in Task 7 (`test_bad_upload_marked_failed`).
5. **Stop pressed twice, or Stop from web while the helper is offline.** Expect: idempotent; the meeting reaches `processing` then `ready` with whatever was uploaded. Test in Task 17 (`test_stop_idempotent_and_offline_helper`).

## Shared event schema (core/fleck_core/events.py, Task 5)

```python
class SegmentEvent(BaseModel):   type: Literal["segment"]; meeting_id: str; segment_id: str; stream: Literal["you","client"]
                                 start_ms: int; end_ms: int; text: str; final: bool; gate: Literal["client","you","overlap"] | None
class AssistEvent(BaseModel):    type: Literal["assist"]; meeting_id: str; assist_id: str; segment_id: str
                                 phase: Literal["thinking","delta","sentence","done"]; question: str
                                 text: str = ""            # delta: new display text; sentence: final sentence text
                                 sentence_index: int | None = None
                                 kind: Literal["library","reference","general","not_in_material"] | None = None  # set on done
                                 from_brief: bool = False; citations: list[Citation] = []
                                 first_words_ms: int | None = None; full_ms: int | None = None; rejected: list[str] = []
class MeetingStateEvent(BaseModel): type: Literal["meeting_state"]; meeting_id: str; status: str
```

`first_words_ms` = wall time of the first displayed answer text minus the wall time at which the question's audio ended (`stream_start_wall + segment.end_ms`). Same for `full_ms` at `done`.

### Task 7: Upload, parse, chunk, embed, index

**Files:** Create `api/fleck_api/library.py`, `core/fleck_core/retrieval.py`, `api/tests/test_library.py`, `core/tests/test_retrieval.py`.

**Interfaces:**
- `parse_document(path: Path) -> list[Block]` where `Block = Text(str) | Table(caption: str | None, header: list[str], rows: list[list[str]])`; markitdown for pdf/docx/pptx/md, openpyxl for xlsx (header = first row with every cell filled; displayed values via `cell.number_format`).

- `Embedder(ollama_url).embed(texts: list[str]) -> list[list[float]]` (`qwen3-embedding:0.6b`, `/api/embed`).
